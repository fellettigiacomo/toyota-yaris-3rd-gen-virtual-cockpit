# fonts_src/

- `DIN_Next_LT_Pro_Regular.otf` -- user-provided source font (Monotype/Linotype
  commercial license, **not** OFL/freely redistributable). Only used to
  generate embedded bitmap glyph subsets for this vehicle's own firmware
  (see `../src/ui/fonts/`); don't publish this OTF file itself if this repo
  is ever made public.
- `DIN_Next_LT_Pro_Bold_Synthetic.otf` -- generated by `../scripts/synth_bold.py`
  (FontForge outline emboldening) from the Regular file above, since only the
  Regular weight was available and the cluster design calls for bold
  throughout. Regenerate with `../scripts/gen_fonts.sh` rather than hand-editing.
  If the real DIN Next LT Pro **Bold** weight file becomes available, prefer
  it over this synthetic version and drop this step.
